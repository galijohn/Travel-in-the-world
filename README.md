# 🌍 המסע שלנו בעולם

גלובוס אינטראקטיבי של כל המקומות שהיינו בהם, יחד וכל אחד לבד.

- **`index.html`**: המפה לשיתוף
- **`edit.html`**: דף העריכה (רק מי שיש לו מפתח GitHub יכול לשמור)

## התקנה כאפליקציה בטלפון
שתי האפליקציות מותקנות בנפרד, וכל אחת מקבלת אייקון משלה במסך הבית:
- **המפה:** פותחים את `https://galijohn.github.io/Travel-in-the-world/`
- **העריכה:** פותחים את `https://galijohn.github.io/Travel-in-the-world/edit.html`

ואז:
- **אייפון (Safari):** כפתור השיתוף ⬆️ ← "הוסף למסך הבית"
- **אנדרואיד (Chrome):** תפריט ⋮ ← "התקן אפליקציה" / "הוסף למסך הבית"

האפליקציות נפתחות במסך מלא, והמפה עובדת גם בלי אינטרנט (עם הנתונים מהפעם האחרונה).
באייפון, האפליקציה המותקנת לא רואה את מה ששמור ב-Safari, ולכן צריך להדביק את מפתח ה-GitHub פעם אחת גם בתוכה.

## עריכה
פותחים את `edit.html` (למשל `https://galijohn.github.io/Travel-in-the-world/edit.html`).

1. בפעם הראשונה מדביקים מפתח GitHub (⚙️ הגדרות, יש שם הסבר איך יוצרים אותו).
   המפתח נשמר רק בדפדפן הזה. בטלפון מדביקים אותו פעם אחת גם שם.
2. מוסיפים מקום בחיפוש עיר, או ב"📍 על המפה" ואז לחיצה על הגלובוס.
3. בוחרים מי היה שם, מתי, כמה מילים וקישור לתיקיית התמונות בגוגל דרייב.
4. לוחצים **שמירה**. המפה הציבורית מתעדכנת בתוך דקה בערך.

## תמונות
לכל מקום ולכל מדינה אפשר לצרף קישור לתיקייה בגוגל דרייב.
בכרטיס של המקום מופיע כפתור "📷 לתמונות מהטיול" שפותח את התיקייה.
כדי שגם אחרים יוכלו לראות אותה: בדרייב ← שיתוף ← גישה כללית ← "כל מי שיש לו את הקישור" (צפייה).

## נתונים
כל הנתונים נמצאים ב-[`data/places.js`](data/places.js). אפשר לערוך אותו גם ידנית.
