# 🌍 המסע שלנו בעולם

גלובוס אינטראקטיבי של כל המקומות שהיינו בהם, יחד וכל אחד לבד.

## איך מעדכנים
כל הנתונים נמצאים בקובץ אחד: [`data/places.js`](data/places.js).

- `countries`: מדינות שנצבעות על הגלובוס
- `places`: ערים או מקומות שמופיעים כנעצים
- `who`: `"together"` (יחד), `"me"` (אני), `"partner"` (בת הזוג), או `["me","partner"]` (כל אחד בנפרד)
- `people`: השמות והצבעים שמוצגים במפה

אפשר לערוך את הקובץ ישירות באתר של GitHub (אייקון העיפרון), והאתר מתעדכן תוך דקה בערך.

## פרסום כלינק (GitHub Pages)
Settings → Pages → Source: *Deploy from a branch* → בוחרים ענף ותיקייה `/ (root)` → Save.
הלינק יהיה: `https://galijohn.github.io/Travel-in-the-world/`

## תמונות
לכל מקום (ולכל מדינה) אפשר להוסיף:
- `album`: קישור לאלבום משותף בגוגל תמונות (שיתוף → יצירת קישור)
- `photos`: רשימת תמונות שמוצגות בכרטיס, למשל `"photos/rome-1.jpg"` (מעלים לתיקייה `photos/`)

## צפייה מקומית

```
python3 -m http.server
```
